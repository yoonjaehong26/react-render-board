# ADR-0092: 전광판은 사용자가 숨기고 위치를 기억한다

- 상태: 채택됨
- 날짜: 2026-08-27
- 관련: ADR-0078, ADR-0080

## 맥락

AI target card 전광판은 선택 순간의 경로를 빠르게 읽게 해 주지만, 앱 상단의 고정 UI와 겹치거나
작업 중 계속 보일 필요가 없을 수 있다. 전광판을 없애면 선택·AI 복사 흐름 자체가 보이지 않게
되므로, 관찰 정보를 끄는 것과 도구를 비활성화하는 것은 분리해야 한다.

## 결정

1. 플로팅 FAB 묶음에 전광판 전용 토글을 둔다. 기본은 켜짐이며, 꺼도 Alt-click/픽 모드의
   선택·하이라이트·target card 생성은 계속 수행한다.
2. 고정된 선택 카드의 이동 핸들을 드래그해 화면 안으로 옮긴다. hover 미리보기는 기존처럼
   pointer-events를 받지 않아 대상 앱 조작을 가로채지 않는다.
3. 표시 여부와 위치는 뷰포트의 0~1 비율로 localStorage에 저장한다. 크기·뷰포트 변경 시에도
   가능한 화면 범위 안에 남고, 저장소를 쓸 수 없으면 이번 세션에서만 동작한다.

## 결과

전광판은 필요한 순간에만 켜는 보조 정보가 되며, 상단 헤더나 고정 UI와 겹치면 고정 선택 뒤
드래그해 피할 수 있다. 핵심 선택 경로는 토글에 종속되지 않고 `interactionStore` 사이드채널
계약(ADR-0080)을 그대로 유지한다.
