# ADR-0096: 패널 크롬을 분리하고 보조 FAB를 접는다

- 상태: 채택됨
- 날짜: 2026-08-27
- 관련: ADR-0040, ADR-0078, ADR-0091, ADR-0092

## 맥락

도킹 방향·공간 확보·분리 창 컨트롤은 패널 가장자리에 절반 걸친 채로 있으면 Canvas 검색
툴바의 입력과 필터를 가린다. 또한 메인 보드·요소 선택·전광판의 세 FAB를 항상 나란히
두면 화면 모서리에서 도구가 필요 이상으로 넓어진다.

## 결정

1. 패널 도킹 컨트롤은 Canvas 툴바 밖의 전용 42px 크롬 바에 둔다. 패널 방향과 무관하게
   검색·필터 행과 같은 좌표를 공유하지 않는다.
2. 보드 열기/닫기는 52px 메인 FAB로 남기고, 요소 선택과 전광판 토글은 28px `…` 도구
   버튼 안에 접는다. 메뉴를 열 때만 두 보조 버튼이 위쪽 세로 목록으로 보인다.
3. 기존 FAB 묶음의 드래그·위치 영속화와 보조 기능의 aria-label은 유지한다.

## 결과

패널 컨트롤이 검색 입력을 덮지 않으며, 평상시 플로팅 영역은 메인 FAB와 작은 도구 버튼만
차지한다. 자주 쓰지 않는 보조 기능은 한 번의 추가 클릭이 필요하지만, 열렸을 때도 화면
가로폭을 늘리지 않는다.
