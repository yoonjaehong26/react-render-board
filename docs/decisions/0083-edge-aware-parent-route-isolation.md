# ADR-0083: edge-aware parent route isolation and single-ink buses

- 상태: 채택됨
- 날짜: 2026-08-26

## 맥락

ADR-0082는 같은 거터의 수평 버스를 span 기준으로 분리했지만, 각 부모 버스가 독립적으로 그려져
다른 층의 수직 스텁·A* 폴백과 교차할 수 있었다. 또한 같은 부모의 fan-out은 논리적으로 하나의
트렁크/바인데도 target마다 SVG edge가 전체 공통 구간을 다시 그려, stroke가 N겹이 되고 target별
그라데이션 색이 섞여 굵기와 색이 불규칙했다.

## 결정

크로스-그룹 배선 pass를 부모(source) 단위로 결정적 순회하고, 먼저 확정된 **다른 부모** 경로의
각 선분을 10px 폭 예약 corridor로 만든다. 이후 부모는 이 corridor를 장애물로 피한다.

- 같은 부모의 fan-out은 계속 하나의 버스다.
- 다른 부모의 버스는 첫 거터가 예약돼 있으면 12px 아래 다음 트랙을 시도한다.
- 거터에서 해결되지 않으면 프레임과 예약 corridor를 함께 피하는 A*로 개별 우회한다.
- 같은 target handle로 들어가는 마지막 짧은 구간만 endpoint 예외로 허용한다. 트리의 공통
  도착점은 물리적으로 한 점에서 합류할 수밖에 없다.
- 버스는 leader edge 하나가 trunk·bar·모든 stub을 SVG subpath로 **한 번만** 그린다. follower edge는
  논리 모델에 남되 잉크는 추가하지 않는다. 버스 색은 단일 source 도메인색으로 통일한다.

## 결과

서로 다른 부모의 경로는 가능한 공간에서는 겹치거나 교차하지 않고, 같은 부모의 분기만 회로도처럼
공유된다. 기존 target별 gradient는 독립 간선에만 남아, 버스에서 색·두께가 뒤섞이는 문제를 없앤다.

경로 예약은 현재 렌더된 크로스-그룹 간선 범위의 순수 계산이다. 공유 target의 최종 핸들 합류,
그리고 화면 밖 노드가 프레임으로 대체된 경우의 의미적 합류까지 금지하지 않는다.
