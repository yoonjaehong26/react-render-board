# ADR-0061: 공유 UI 레인 (다중 부모 컨테이너를 트리에서 빼 별도 레인으로) — 안정 골격 pillar ②

- 상태: 채택됨(구현 — 증분 1 리프 + 증분 2 자식 있는 공유 컨테이너)
- 날짜: 2026-07-18

## 맥락 (Context)

[안정 골격 설계](../research/2026-07-18-stable-skeleton-shared-ui-lane.md)의 3기둥 중 ②. 배경:

- 실제 React 렌더 트리(인스턴스 단위)는 항상 **단일 부모 = 순수 트리**다. "다중 부모"는 **같은 파일/타입을 그룹으로 접을 때만** 생기는 아티팩트 — 공유 **컨테이너**(자기 서브트리를 렌더하는 컴포넌트)가 여러 파일에서 쓰이면 그 그룹이 부모를 여럿 갖는다(공유 **리프** Button은 host만 렌더해 자기 그룹을 안 만들므로 다중 부모가 안 됨 → 문제 아님).
- 이 다중 부모 DAG가 tidy-tree(ADR-0058)를 흔든다: 대표 부모 재선택으로 자발적 요동, 다경로 깊이로 밴드 흔들림, 긴 횡단 간선.
- 실증: 재현 fixture `Dialog.tsx`(SettingsDialog/ProfileDialog 두 파일이 씀)로 `Dialog.tsx` 그룹이 부모 2개를 갖는 DAG를 도구에서 처음 재현했다.
- 사용자 결정: "B(레인 구현) 자체가 A(아픔 실증)다" — 레인을 만들어 before/after로 검증한다. 정적 교차 측정(`scripts/measure-edge-crossings.mjs`)으로 **현 데모 교차 24개가 전부 "같은 부모 팬" 기하 문제이고, 다중부모(Dialog) 연루 교차는 0**(부모 인접)임을 확인 — 레인의 주 효과는 정적 교차 제거가 아니라 **DAG 제거 → 순수 트리 → 구조 안정성**이다.

## 결정 (Decision)

**다중 부모 그룹(`groupParents ≥ 2`)을 tidy-tree에서 빼 아래 별도 "공유 레인" 밴드에 둔다.** 남은 트리는 모든 노드가 단일 부모 = 순수 트리가 된다.

**배치(`layout.ts`):**
- `sharedGroups = { g : groupParents.size ≥ 2 }`. 이들을 스패닝 트리의 **부모 후보에서도 제외**(그 밑에 트리 자식을 안 놓음 → 트리 순수성 보장)하고, 깊이 밴드에서 빼 트리 맨 아래 + 여유 간격 아래 **레인 밴드**에 좌→우(groupOrder)로 순차 배치. `GroupLayout`에 `shared`/`parentCount` 노출.

**표현(`toFlow.ts`/`GroupNode`/`ComponentNode`/`flow.css`):**
- **상시 선 폐지 + 인라인 칩.** 처음엔 사용처→공유를 곡선(bezier)으로 그렸으나, 실측 피드백 — 레인이 아래라 선이 **화면을 가로지르는 긴 선**이 됐다. 그래서 상시 선을 **없애고**, 공유 컨테이너를 렌더하는 부모 노드에 **"↘X 공유" 인라인 칩**(`ComponentNode`)으로 로컬 표식만 한다("여기 공유 X 씀"이 사용처에서 바로 읽힘 — Figma 레퍼런스가 index.jsx마다 "Modal" 탭 붙인 방식). 전체 연결은 **호버 시에만 점등**(후속: 칩 호버=인라인 peek+옅은 직선 / 레인 호버=전체 사용처 점등).
- **레인 배치 = 부모 x 중심(centroid) 아래.** 공유 그룹을 x=0에 몰지 않고 부모들의 중심 아래에 둬(겹치면 우측 밀기) 호버선도 짧게. 부모가 뭉쳐 있으면 짧은 수직 낙하.
- **공유 그룹 프레임 = 사선 해치 배경**(스윔레인 언어) + **"×N 사용" 배지**(리스트 접기와 같은 카운트 언어).

## 근거 (Rationale)

- **문제의 정확한 원천.** 자발적 요동의 유일한 원인이 다중 부모 DAG라, 그것만 빼면 트리가 순수해져 안정+교차 0(공짜). 아키텍처 다이어그램 표준(스윔레인/C4의 "스토어·훅은 트리와 직교")과 일치, 사용자 Figma 레퍼런스(공유 UI를 별도 구역)와도 일치.
- **탐지가 공짜.** `groupParents`를 엔진(`computeGroupDepths`)이 이미 계산 — `fiber.type` 추적 불필요. 거짓양성 없음(부모 ≥2 = 정의상 여러 곳에서 인스턴스화).
- **ADR-0058 부분 개정.** 기존엔 공유 그룹을 "대표 부모 아래"에 뒀다(간선으로 나머지 부모 연결). 이제 레인으로 빼 트리에서 완전히 제거 — ADR-0058의 대표-부모 스패닝은 유지하되 공유 그룹은 그 트리 밖.

## 범위·유예 (Scope)

- ~~**증분 1 = 리프 공유 컨테이너**~~ → **증분 2 완료**: 자식 있는 공유 컨테이너도 처리한다. 전체 스패닝 트리(공유 그룹도 자식 유지)를 만든 뒤, **공유 컨테이너 + 그 서브트리 전체(`isLaned`: 공유거나 primary 부모가 레인)를 레인에 미니 tidy-tree로** 함께 옮긴다(컨테이너 위, 자식 아래 — 고아 방지). tidy-tree 배치는 `layoutForest`로 추출해 메인 트리·레인 포레스트 양쪽에 재사용. 레인 루트는 부모 centroid 아래로 서브트리째 shift + 좌→우 겹침 해소. shared 플래그(배지·해치)는 실제 공유 컨테이너에만, 레인 자식은 일반 프레임. fixture `nested-shared/`(SharedCard→CardBody, 두 파일이 씀)로 실증, 유닛 테스트 추가.
- **임계값** `N=2`(순수). 두 곳만 쓰면 트리에 두는 `N=3` 튜닝은 근거 나오면.
- **곡선 co-design**: 곡선 스타일은 배선 영역과 겹치므로, 향후 공유 간선 버스 병합은 배선과 함께.
- **먼 부모/실앱 스트레스**: 현 fixture는 부모 인접이라 레인의 극적 효과(긴선·요동 제거)가 정적으로 잘 안 보인다. 먼 부모 시나리오/실앱에서 재확인은 후속(기능은 동작 실증됨).

## 결과 (Consequences)

- **바뀐 것**: `layout.ts`(shared 탐지·트리 제외·centroid 레인 배치), `toFlow.ts`(shared 그룹 data·사용처 칩 맵·상시 선 폐지), `ComponentNode`(↘칩), `GroupNode`(레인 클래스·배지), `flow.css`(칩·레인 배경·배지). 데이터/노드 좌표 불변.
- **검증**: 유닛 335개 통과(layout 공유 테스트를 "레인 이동 + centroid 배치"로 갱신·단언 추가). 실측 — Dialog가 부모 centroid 아래 레인으로 이동, 사용처에 "↘Dialog" 칩 2개, 상시 선 0, "×2 사용" 배지, 콘솔 에러 0. 트리 팬 교차 24는 별개 이슈(기하 planarity)로 잔존.
- **칩 색 통일 + 호버 on-demand 선(구현)**: 칩 배경 = 그 공유 컨테이너의 팔레트 색(칩↔레인 그룹이 같은 색으로 묶여 멀리서도 읽힘), 솔리드 pill. **사용처 노드 호버 → 공유 그룹으로 직선 점등 / 레인 그룹 호버 → 모든 사용처로 점등**(직선=기하 채널, 색=팔레트 통일, 애니메이션). 상시 선 없이 필요할 때만. 한계: 타깃이 화면 밖(RF 컬링)이면 선 미표시 — centroid 배치로 대개 함께 보임(실측 1선 점등 확인).
- **인라인 peek — 클릭 토글(구현)**: 칩을 `<button>`(pointer-events 되살림, stopPropagation으로 노드 선택 차단)으로 만들어 **클릭하면 인라인 peek 카드 토글**. 카드는 그 공유 컨테이너의 **접힌 실제 인스턴스 내용**(멤버 컴포넌트 이름, toFlow가 전체 nodes에서 수집)을 점선 테두리 "미리보기"로 펼친다. 호버 팝오버 대신 클릭 토글 — 안정적 + 키보드 접근성(버튼). 실측: Dialog 칩 클릭 → "Dialog · 미리보기" [DialogHeader, DialogBody], 재클릭 닫힘.
- **on-demand 선 = 공유 UI 위쪽(top) 진입(구현)**: 공유 그룹을 항상 edge의 target으로 둬 선이 공유 UI의 top 핸들(위쪽 가장자리)로 들어온다(사용자 요청). 사용처 호버=그 노드→공유 top / 레인 호버=모든 사용처→공유 top.
- **남긴 것**: 화면 밖 타깃은 RF 컬링으로 선 미표시(centroid로 대개 함께 보임) — 필요 시 커스텀 오버레이로 승격.
- **되돌리기**: `sharedGroups` 분기 제거 → ADR-0058 "대표 부모 아래" 동작. 순수 프레젠테이션/배치.
