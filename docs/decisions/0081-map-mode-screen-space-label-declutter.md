# ADR-0081: 지도 모드 screen-space 라벨 declutter

- 상태: 채택됨
- 날짜: 2026-08-26

## 맥락

ADR-0018은 `minZoom=0.001`까지 내려간 지도 모드에서 그룹명을 읽을 수 있도록 라벨에
`1 / zoom` counter-scale을 적용했다. 프레임은 계속 축소되는데 라벨만 화면 기준 크기를
유지하므로, 파일/컴포넌트 그룹이 수십 개 이상 가까이 모이면 라벨이 서로 겹쳐 지도를 읽을 수
없게 됐다. 이는 ADR-0018이 의도적으로 남긴 후속 과제였다.

## 결정

`GroupLabelDeclutter`가 지도 모드에서만 실제 DOM의 `getBoundingClientRect()`를 읽고, **화면
좌표** 기준 충돌을 제거한다.

- 이름이 아니라 실제 픽셀 rect를 사용한다. 월드 좌표는 zoom과 counter-scale을 동시에 반영하지
  못해 충돌 판정 기준이 될 수 없다.
- 검색·DOM 선택·props 추적 그룹은 충돌해도 항상 남긴다. 검색은 언제나 탈출구여야 한다.
- 나머지는 그룹 멤버 수가 큰 순으로 greedy하게 남기며, 동률은 group id로 정렬해 라이브 커밋마다
  표시 대상이 흔들리지 않게 한다.
- 숨기는 대상은 라벨 헤더뿐이다. 그룹 프레임·색·집계 엣지는 유지되므로 지도 구조와 밀도는 잃지
  않는다. 상세 모드로 돌아오면 모든 라벨을 즉시 복원한다.
- 상태를 각 `GroupNode`에 React props로 내리지 않고 rAF 뒤 DOM class/`aria-hidden`만 바꾼다.
  줌 중 수십~수백 노드를 재렌더하지 않아 ADR-0017의 대형 트리 성능 계약을 보존한다.

## 결과

극단적인 zoom-out에서도 대표 라벨만 서로 겹치지 않게 남고, 사용자가 찾는 대상은 이름으로
계속 추적할 수 있다. 검색 결과가 서로 겹치는 특수 경우에는 둘 다 유지한다. 이 경우 정확한
검색 신호를 감추는 것보다 일시적 겹침이 낫다.

순수 충돌 선택 로직은 `labelDeclutter.test.ts`로 검증한다. 실제 픽셀 rect와 React Flow DOM의
연결은 브라우저 런타임 관심사라 일반 보드 회귀 검증에서 확인한다.
