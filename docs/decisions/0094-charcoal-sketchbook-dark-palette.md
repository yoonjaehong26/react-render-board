# ADR-0094: Charcoal Sketchbook 다크 팔레트

- 상태: 채택됨(구현)
- 날짜: 2026-08-27

## 맥락

기존 다크 모드는 Tailwind 계열의 차가운 navy/slate 표면과 고채도 네온 팔레트를 썼다. 다크
화면에서의 대비는 충분했지만, rough.js 테두리·햇칭·손글씨 워드마크로 만든 스케치북 정체성과는
질감이 달랐다. 사용자는 그 손그림 언어는 유지하면서 팔레트만 더 정제하기를 원했다.

## 결정

다크 모드를 **Charcoal Sketchbook**으로 바꾼다.

- 표면은 먹색 종이(`#171716`), 패널은 짙은 회갈색(`#1e1e1c`), 보조선은 연필 회색(`#403f39`)을
  쓴다. 본문은 따뜻한 종이색(`#e8e2d5`), 보조 텍스트는 `#aaa69b`로 둔다.
- 도메인 팔레트의 라이트 색/그룹 이름 해시/8색 인덱스는 바꾸지 않는다. 다크 변형만 인디고
  연필·하늘 크레용·민트 마커·세이지·보라·로즈·산호·황토의 낮은 채도 색으로 바꾼다.
- 노드 배경 tint는 약 11%로 제한한다. 프레임·rough 선·간선에는 해당 도메인색을 그대로 써서
  그룹 식별은 유지하되, 넓은 캔버스가 색 안개처럼 보이지 않게 한다.
- 검색·추적·오류처럼 행동을 나타내는 색은 도메인 팔레트에 편입하지 않는다. 상태는 계속
  초록/청록/산호 계열의 별도 언어다.

## 결과

- 다크 보드는 일반적인 개발자 대시보드가 아니라 어두운 종이에 색연필로 그린 구조도처럼 읽힌다.
- `paletteHex()`를 단일 색 소스로 유지하므로 그룹 프레임, rough 노드 테두리, MiniMap, 기본 간선,
  hover 혈통이 같은 도메인색을 계속 공유한다.
- 데이터 스키마·레이아웃·상호작용은 바꾸지 않는 프레젠테이션 변경이다.
