# ADR-0095: 매우 넓은 그룹의 rough 프레임 폴백

- 상태: 채택됨(구현)
- 날짜: 2026-08-27

## 맥락

그룹 프레임은 `roughjs`가 해당 크기의 SVG를 만든 뒤 CSS `background-size: 100% 100%`로 그린다.
일반적인 파일 그룹에서는 손그림 테두리가 잘 읽히지만, 한 행에 많은 자식 파일을 둔 strict
waterfall의 매우 넓고 낮은 프레임에서는 모서리의 스케치 선이 긴 변과 어울리지 않아 중앙으로
내려온 것처럼 보인다.

## 결정

펼쳐진 그룹이라도 `width / height > 8`이면 rough SVG rectangle 전체를 쓰지 않는다. 대신 도메인색
CSS 실선 프레임(`group-node--rough-fallback`)과 **확대율의 역수를 곱한 outline**을 쓴다. 일반
border만 쓰면 캔버스를 줌아웃할 때 1px 아래로 줄어 긴 프레임이 다시 사라져 보이므로, outline은
화면에서 항상 1.8px 연필 실선으로 보이게 한다. 위·아래에 rough.js 선 조각을 반복하는 방식도
검토·구현했으나, 조각의 이음새가 규칙적으로 보여 더 인공적인 패턴이 됐다. 따라서 긴 프레임에는
rough 질감을 억지로 유지하지 않는다. 점선은 캔버스 점 격자와 섞여 긴 프레임이 없는 것처럼
읽히므로 접힌 그룹 전용으로 남긴다. 비율이 8 이하인 일반 그룹은 기존 rough 프레임을 계속 쓰며,
접힌·지도 모드·pending 그룹의 기존 대시 표현도 바꾸지 않는다.

## 결과

- 긴 프레임에서 모서리를 벗어난 rough 선이 생기지 않고, 줌아웃해도 프레임 상·하단이 사라지지 않는다.
- 도메인색·배경 tint·라벨·그룹 크기 계약은 변하지 않으므로 배치와 상호작용에 영향이 없다.
- "모든 선을 rough로"보다 프레임 비율에 따라 rough rectangle과 선명한 연필 실선을 구분하는
  하이브리드 표현이 스케치북 정체성과 큰 구조도의 가독성을 함께 지킨다.
