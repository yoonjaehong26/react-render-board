# ADR-0001: 범위를 React 전용으로 한정

- 상태: 채택됨
- 날짜: 2026-07-17

## 맥락

멀티 프레임워크(Vue, Svelte 등) 지원을 고려할 수 있는가?

## 결정

React 전용으로 한다.

## 근거

기술 스택 전체(bippy / react-devtools-core, Fiber 트리 순회)가 React의 내부 구조에 직접 묶여 있다. Vue의 가상돔, Svelte의 컴파일 구조는 완전히 다른 내부 표현을 쓴다. 멀티 지원은 프레임워크마다 별도 구현이 필요하다.

즉 이것은 "초기 선택"이 아니라 **구조적으로 고정된 사실**에 가깝다.

## 결과

- 이름도 예측 가능하게 `react-` 접두사로 간다 (→ ADR-0003).
- 나중에 확장하고 싶으면 프레임워크별 어댑터를 추가하는 형태가 될 것.
