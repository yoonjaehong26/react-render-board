# ADR-0082: span-aware cross-parent edge tracks

- 상태: 채택됨
- 날짜: 2026-08-26

## 맥락

ADR-0060은 같은 그룹 층의 출발 노드를 x 순서로 11px씩 쌓아 다른 부모의 버스 바를 분리했다.
하지만 44px 상한 이후에는 모든 추가 버스가 같은 마지막 트랙으로 clamp돼 다시 완전히 포개졌다.
반대로 수평 구간이 멀리 떨어진 버스까지 매번 새 트랙을 받아, 필요 없는 세로 여백도 만들었다.

## 결정

트랙 배정 입력을 출발 x 하나에서 **출발 노드별 실제 버스 span**(source 중심에서 모든 target 중심까지의
최소/최대 x)으로 바꾼다. 같은 거터에서는 interval partitioning으로 다음을 보장한다.

- span 사이에 12px 이상 여백이 있으면 같은 y 트랙을 재사용한다.
- span이 닿는 서로 다른 부모 버스는 11px 간격의 서로 다른 y 트랙을 쓴다.
- 고정 44px clamp는 제거한다. 거터를 넘어 프레임을 관통하게 되는 버스는 기존 `routeCrossGroupBuses`
  안전장치가 해당 간선만 개별 A*로 폴백시킨다.
- 같은 출발 노드의 fan-out은 기존처럼 하나의 트렁크/바를 공유한다.

## 결과

"부모가 다르면 무조건 다른 높이"가 아니라, 실제 겹치는 구간에서만 간격을 써서 가독성과 공간
효율을 함께 유지한다. 경로는 source/span 순으로 결정돼 라이브 커밋에도 안정적이다.

수직 스텁끼리의 corridor 충돌과 여러 층을 가로지르는 간선의 전역 조율은 여전히 후속 과제다.
